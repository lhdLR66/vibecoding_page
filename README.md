# 🚀 个人工作看板

一个现代时尚、有趣好玩的个人工作看板，用于日常工作效率管理。

## ✨ 功能特性

### 🎨 设计特色
- **现代时尚UI**：2025-2026流行设计趋势
- **毛玻璃效果**：玻璃态设计增加现代感
- **柔和渐变色彩**：主色调浅蓝，搭配绿色、珊瑚红、黄色
- **游戏化元素**：成就徽章、进度动画、有趣交互
- **响应式设计**：完美适配手机、平板、电脑
- **亮色/暗色主题**：一键切换，保护眼睛

### 📊 功能模块
1. **销售数据看板** - 趋势图表、目标完成率、客户分析
2. **项目管理看板** - 可拖拽的Kanban板（待办/进行中/已完成）
3. **个人日报系统** - 任务清单、工作日志、时间追踪
4. **快速统计面板** - 今日任务、会议、销售额、专注时间
5. **日历视图** - 交互式日历，显示会议和截止日期
6. **团队协作区** - 同事状态、消息通知、快速聊天
7. **目标追踪** - 进度条、成就徽章、里程碑
8. **资源监控** - 存储空间、API调用、系统状态

### 🎮 交互体验
- **拖拽排序**：项目管理卡片可自由拖拽
- **实时更新**：数据自动刷新和统计
- **微交互动画**：悬停效果、点击反馈、完成动画
- **通知系统**：实时提醒和消息提示
- **主题记忆**：自动保存用户的主题偏好

## 🚀 快速预览

### 方法1：使用预览服务器（推荐）
```bash
# Windows用户
双击 preview.bat

# macOS/Linux用户
chmod +x preview.sh
./preview.sh

# 或直接使用Python
python preview.py
```

服务器启动后，在浏览器中访问：http://localhost:8000

### 方法2：直接打开文件
直接双击 `index.html` 文件，用浏览器打开即可。

### 方法3：使用其他HTTP服务器
```bash
# 使用Node.js的http-server
npx http-server .

# 使用Python的简单HTTP服务器
python -m http.server 8000
```

## 🛠️ 技术栈
- **HTML5** - 语义化标签，现代Web标准
- **CSS3** - 变量、网格布局、Flexbox、动画
- **JavaScript (ES6+)** - 现代JavaScript特性
- **Chart.js** - 数据可视化图表
- **Font Awesome** - 图标库
- **Google Fonts** - 现代字体

## 📱 响应式设计
- **桌面端** (≥1200px)：完整布局，多列显示
- **平板端** (768px-1199px)：自适应布局，两列显示
- **手机端** (<768px)：单列布局，触摸友好

## 🔧 自定义配置
你可以通过修改以下文件来自定义看板：

1. **修改主题颜色**：编辑 `style.css` 中的CSS变量
2. **调整布局**：修改 `style.css` 中的网格布局
3. **更新数据**：编辑 `script.js` 中的模拟数据
4. **添加功能**：在 `script.js` 中扩展JavaScript功能

## 🚀 部署到GitHub Pages
1. 创建GitHub仓库
2. 将所有文件推送到仓库
3. 在仓库设置中开启GitHub Pages
4. 访问 `https://[你的用户名].github.io/[仓库名]`
